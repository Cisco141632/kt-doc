Notice spelling patterns

PatternExamplesMemory action
Short vowel + final consonantrun → running; plan → plannedDouble the final consonant.
Final silent emake → making; use → usingDrop e before -ing.
Consonant + ytry → tried; study → studiedChange y to i before -ed.
Common -tion endinginformation, solution, completionHear “shun”; write -tion.

Use your mistakes

  2. Copy the correct word once.
  3. Hide it and write it from memory three times—not ten times while looking.
  4. Use it in a true sentence.
  5. Test it again tomorrow.
