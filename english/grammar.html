Grammar that you use

Grammar is a set of useful patterns. Start with time: usual, now, finished, or future.

Choose the time first

UsualI work every day.Present simple: routines and facts.
NowI am working now.Present continuous: happening now.
FinishedI worked yesterday.Past simple: finished past action.
Future planI will work tomorrow.Will: decision or prediction.
PlannedI am going to work tonight.Going to: an existing plan.
ExperienceI have worked here for a year.Present perfect: past connected to now.

Finished past actions

Regular verbs often add -ed: work → worked, complete → completed, test → tested. Some common verbs change: go → went, send → sent, make → made, take → took, find → found.

Do not memorise everything at once

  1. Decide the time.
  2. Choose the subject.
  3. Choose the matching verb form.
  4. Add the rest of the idea.
  5. Read it aloud. Does it sound complete?
