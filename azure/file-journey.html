Follow one PDF from upload to AI output

Trace complaint.pdf through the browser, backend, Azure, AI service, and database. Then compare the lifecycle of other case files.

By the end, you can…

  • Describe all nine stages of the uploaded-PDF flow.
  • Separate who decides a key from who uploads the bytes.
  • Classify case files by routing and saved-versus-built behavior.

Give the story a concrete owner

In the guide’s worked example, case 9001 belongs to the customer Maharastra. Its media root is crimeos-backend-maha-police-prod/mahapolice-prod/media. We will follow one original PDF and the text derived from it. They are two blobs, with two saved references.

The account root is important, but it is only part of the full address. The selected Azure account and the reader’s configured container also have to agree. The browser exercise below uses fictional account names and sends no network requests.

“The backend decides the key” does not mean the PDF must travel through the backend. In the described flow, the browser transfers bytes directly to storage. The database stores the reference and metadata; the storage account stores the PDF.

Later reads use the saved derived key. Merely knowing the current case ID is not enough to reconstruct the original upload UUID or the AI run’s output name. The saved reference preserves that exact object identity.

Diagnose the stage, not just the filename

If upload succeeds but extraction fails, verify the AI’s read grant and the original object. If AI output upload succeeds but the app cannot show text, compare the callback key with extracted_text_key. If a bundle is stale, inspect the bundle/index publication workflow rather than renaming the original PDF.

Predict first: The original PDF opens, but its extracted text is missing after a migration. Does that prove storage access is correct for both?

No. They are distinct objects with distinct saved references. Inspect each exact key, its route, and whether its bytes were copied. The original being present does not recreate the derived text.

Remember in 30 seconds

  • The backend chooses keys, while the browser and AI can upload bytes directly with grants.
  • Original and derived files have separate saved references.
  • Use the file-type catalog before assuming that every missing file can be rebuilt.
