1. Two Azure storage accounts each contain private-files/cases/214/a.pdf. Are these the same stored object?

No. The complete coordinates include the storage account.

A blob is identified by the account, container, and exact key together. Different accounts contain independent objects.

4. The AI has a valid write-only SAS for derived/a.md. Can it download original.pdf with that grant?

No. The resource and requested operation are outside that grant.

A write grant for one derived file does not authorize reading another blob. Request the appropriate backend grant.

5. Why does the described AI service receive signed URLs instead of the account-key connection string?

The account-key connection string can give broad account access; grants can be narrowly scoped and temporary.

The backend retains the broad credential and delegates only the case-file operation the AI needs.

6. A five-minute read link is used ten minutes after it was issued. What is the useful next action?

The original grant has expired. A fresh grant must still be for the correct resource and permitted operation.

8. A Delhi user opens a case whose station belongs to Maharastra. Which customer owns a new file for that case?
