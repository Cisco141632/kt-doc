One file, three coordinates

Storage accountThe building: a distinct place in Azure
→
ContainerThe cupboard inside that building
→
Blob keyThe full name of one stored object

CrimeOS adds a routing decision: it examines the start of the blob key to select a storage connection. The customer who owns a case influences how that key is built. That is why learning the key is as important as learning the URL.

Two kinds of knowledge

Azure concepts explain the storage service. CrimeOS examples explain the application behavior described in your November 6, 2026 guide. The routing rule and URL parser belong to CrimeOS.

Use a prediction before every click

  1. Read: learn the term in plain language.
  2. See: follow the diagram and one concrete file.
  3. Predict: say which account, key or permission should be used.
  4. Try: change one input in the lab and inspect the result.
  5. Explain: answer the lesson check and read the reason.
  6. Recall: revisit the quiz after a break.

The labs use fictional examples and an in-memory model. They do not connect to Azure, upload your files, inspect your database or generate real credentials. Lesson text and answer explanations remain readable without JavaScript.
