Module 15 / 18 · about 25 minutes

The visual tmux playground

Try a safe model of sessions, windows, panes and detachment. Every action changes a visible workspace and explains its effect.

By the end, you can…

  • Complete six missions using buttons or supported commands.
  • Observe focus, zoom and session lifecycle changes.
  • Transfer the practice to the real terminal labs.

Learn by changing the workspace

A learning simulation

This is not a shell or a real tmux process. It models a documented subset of commands, defaults and key sequences. It does not run programs, access your files, connect with SSH, or model advanced targeting/configuration. Unsupported commands return an explanation.

The simulator’s command vocabulary

Supported simulated commands — explicit aliases are listed by help
tmux new-session -s api
tmux list-sessions
tmux attach-session -t api
tmux switch-client -t api
tmux detach-client
tmux new-window -n tests
tmux rename-window editor
tmux select-window -t 0
tmux split-window -h
tmux split-window -v
tmux select-pane -t 0
tmux resize-pane -Z
tmux select-layout tiled
tmux next-layout
tmux kill-pane
tmux kill-session -t api
help

Inside the simulator, the visible buttons are equivalent actions. The command field also accepts supported tmux commands without the leading tmux. Targets are limited to the simple names and indexes shown in the model. Shell pipelines, compound commands, arbitrary flags, configuration, full-screen applications and filesystem paths are not interpreted.

Keyboard practice is scoped to the playground: focus its command input, then press Ctrl+b followed by %, double quote, c, o, n, p, l, z, d, a window digit or Space (cycle layouts). The on-screen buttons provide the same actions if your browser captures a key. Ctrl+b outside the playground is never intercepted.

Remember in 30 seconds

  • A session groups windows; a window arranges panes.
  • Focus, zoom and detach change different parts of the model.
  • The simulator teaches state changes; real labs teach your terminal environment.
