Module 08 / 18 · about 35 minutes

Build a configuration you understand

Add useful settings one at a time and learn how option scope, key tables and reload behavior work.

By the end, you can…

  • Read and safely reload a tmux configuration.
  • Distinguish server, session, window and pane settings.
  • Customize keys, paths, status and plugins without losing control.

When configuration is read

tmux reads its configuration when the server starts, not every time you create a session. The usual personal file is ~/.tmux.conf; modern versions also support XDG locations. Check FILES in your installed manual for search order. A -f argument chooses a file at server startup.

Reload into an existing server
tmux source-file ~/.tmux.conf

Reloading executes the file’s commands in order. It is not a transactional reset: earlier lines may apply even if a later line fails. Removing a setting from the file does not unset its already-loaded value. Use set-option -u for an appropriate local override or explicitly restore the intended global value.

Test major changes on an isolated server with tmux -L config-check -f /path/to/test.conf new -s check. Opening a new session on an existing server does not retest startup configuration.

A small, commented starting point

Read this before copying. The default prefix stays Ctrl+b so the lesson shortcuts continue to match. The same file is available as a downloadable starter config.

Configuration — ~/.tmux.conf
# Increase scrollback for panes created after this setting.
set -g history-limit 20000
# Let the mouse select panes, resize borders and enter copy mode.
set -g mouse on
# Choose explicit copy-mode keys.
setw -g mode-keys vi
# Human-friendly indexes for NEW windows and panes.
set -g base-index 1
setw -g pane-base-index 1
set -g renumber-windows on
# Open splits in the current pane's directory.
bind % split-window -h -c "#{pane_current_path}"
bind '"' split-window -v -c "#{pane_current_path}"
bind c new-window -c "#{pane_current_path}"
# Reload the usual personal config; commands are separated by a semicolon.
bind r source-file ~/.tmux.conf \; display-message "Config reloaded"
# Keep status information simple and readable.
set -g status-left "[#S] "
set -g status-right "#{pane_current_command} | %H:%M"
set -g status-interval 5

set aliases set-option; setw aliases set-window-option. Quoting #{pane_current_path} keeps spaces in paths intact. A command containing semicolons has two parsing layers when entered through a shell; escape the separator as shown in shell/config examples.

Set the right option at the right scope

ScopeInspectMeaning
Servertmux show-options -sOne value for the whole server, such as escape-time or set-clipboard.
Global session defaultstmux show-options -gFallback values for sessions without local overrides.
One sessiontmux show-options -t apiSession-specific values. Add -A to include inherited values.
Global window defaultstmux show-window-options -gDefaults for window options such as mode-keys.
One windowtmux show-window-options -t api:0Overrides for the chosen window.
One panetmux show-options -p -t %3Supported pane options; inspect the manual for inheritance rules.

For example, set -w synchronize-panes on affects a window. It copies keyboard input into other panes in that window, so turn it off immediately after a controlled task. A global default can be masked by a local override. Inspect both before concluding that reload failed.

Key tables and a deliberate prefix change

Optional configuration — changes all later prefix sequences
set -g prefix C-a
unbind C-b
bind C-a send-prefix
bind -r H resize-pane -L 5
bind -r L resize-pane -R 5

bind uses the prefix table by default. -r allows repetition within the repeat-time interval. bind -n creates a root-table binding with no prefix and can steal keys from applications. bind -T copy-mode-vi affects only that copy-mode table.

If you choose Ctrl+a, it conflicts with a common shell start-of-line shortcut. Press Ctrl+a twice with the shown binding to send a literal Ctrl+a to the program. Keep a recovery route: from another shell, restore tmux set -g prefix C-b and tmux bind C-b send-prefix.

Colors, status and plugins: add only what you understand

Check infocmp tmux-256color before choosing set -g default-terminal "tmux-256color". Programs use TERM to find terminal capabilities; do not force an unrelated TERM in shell startup files. True-color features should describe the actual outer terminal, not a guessed one. The troubleshooting clinic covers the diagnosis.

The status line uses formats such as #S (session), #I (window index), #W (window name), and #{pane_current_path}. A #(shell command) segment launches a shell command; expensive status commands can slow down refreshes.

TPM manages third-party plugins; tmux-resurrect saves layout and selected program state; tmux-continuum can automate periodic saves. These tools are optional. Inspect their source and version-specific instructions before installing because plugins execute code as your user. They do not checkpoint arbitrary process memory or resurrect a running transfer after a reboot. Try native features first, then add one plugin and verify what it changes.

Pause and test your understanding

Remember in 30 seconds

  • Reload executes commands; it does not undo removed settings.
  • Scope and inheritance explain many configuration surprises.
  • Keep a small config, inspect active bindings, and add plugins deliberately.
