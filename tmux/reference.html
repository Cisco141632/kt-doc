The field reference

A searchable command sheet, practical glossary and primary sources for deeper study.

By the end, you can…

  • Find the right command by task.
  • Use defaults without assuming your config matches.
  • Know where to check complete, version-specific behavior.

Task → shortcut → command

Every shortcut below starts with Ctrl+b, release, then the listed key. These are default bindings. Commands are shell examples; omit the leading tmux at the tmux command prompt. Replace example names and IDs with inspected targets. A slash between two commands means alternatives, not text to paste.

Vocabulary in plain language

Client
A connection from an outside terminal to a tmux server.
Server
The process managing sessions, terminal state and pane programs.
Socket
A local communication endpoint that identifies a server.
Session
A named collection of linked windows, with one current window.
Window
An arrangement of panes; may be linked to multiple sessions.
Pane
A terminal running a program within a window.
Prefix
A key sequence that asks tmux to interpret the next key.
Key table
The mapping from keys to actions for a context, such as prefix or copy-mode-vi.
Copy mode
A mode for moving through retained output, searching and selecting text.
Paste buffer
Text stored inside tmux; distinct from a desktop clipboard.
Target
A session, window, pane or client selected by name, index or ID.
Format
A tmux-expanded expression such as #{pane_id}, used in status or command output.
Hook
A tmux command triggered by a specified event.
PTY / pseudoterminal
The terminal interface through which a pane’s programs receive input and produce output.
TERM / terminfo
A terminal capability name and its database entry, used by programs to draw correctly.
OSC 52
A terminal escape sequence that can transport clipboard text when every layer supports and permits it.
Control mode
tmux’s protocol interface for external programs, distinct from its normal terminal UI.
Session group
Sessions with a shared window list and independent current-window selection.

Primary sources and scope

Core examples use established tmux 3.2+ features. Version-specific sections should be checked against the server actually running your sessions. Documentation reviewed in October 2026; upstream pages can describe features newer than distribution packages.

  • Official getting-started guide — concepts, interaction and version-labeled features.
  • Version-pinned tmux 3.5a manual source — stable reference for core command semantics.
  • OpenBSD tmux manual — complete reference; may describe a newer version than yours.
  • Official installation guide — packages and source builds.
  • Official clipboard guide — OSC 52, terminal capabilities and external clipboard tools.
  • Official FAQ — TERM, terminal issues and debugging.
  • TPM, tmux-resurrect, tmux-continuum — optional plugin maintainers’ own documentation.

This course covers the practical end-to-end workflow and introduces advanced facilities. For every command flag, format operator, hook and version addition, use the installed man tmux and list-commands; an educational reference is not a replacement for the full manual.

Remember in 30 seconds

  • Inspect the active bindings rather than trusting someone else’s cheatsheet.
  • Use explicit targets and understand the scope of close operations.
  • The installed manual resolves version-specific details.
