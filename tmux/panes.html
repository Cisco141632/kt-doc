Module 06 / 18 · about 30 minutes

Panes, layouts & focus

Split the screen intentionally, understand split direction, and keep track of the pane receiving your input.

By the end, you can…

  • Create side-by-side and stacked panes.
  • Select, resize, zoom and rearrange panes.
  • Keep working directories and close operations predictable.

See the two split directions

Side by side

left
right

Ctrl+b then %
split-window -h

One above another

top
bottom

Ctrl+b then "
split-window -v

The -h direction places panes along the horizontal axis; the divider is vertical. The -v direction places panes along the vertical axis; the divider is horizontal. This vocabulary causes many first-day mistakes.

Run in your shell
tmux split-window -h
tmux split-window -v -c "#{pane_current_path}"

A split divides the active pane, not necessarily the whole window. -f spans the full window dimension; -b puts the new pane before the current one. -d keeps focus in the existing pane. -c sets the starting directory.

Always know where the next command will go

Prefix, then…Result
Arrow keyMove focus to a neighboring pane.
oCycle active pane.
q, then a displayed numberShow pane indexes, then select one before the labels disappear.
zZoom this pane to fill the window; repeat to restore the layout.
SpaceCycle predefined layouts.
{ / }Swap with the previous / next pane.
!Break the current pane out into a separate window.
xAsk to kill the active pane; inspect its running program before confirming.

The active pane’s border is highlighted. Zoom hides other panes without stopping them. If a pane seems to have vanished, look for the Z status flag and toggle zoom before rebuilding the layout.

Resize and choose a useful arrangement

Run in your shell
tmux resize-pane -R 5
tmux resize-pane -D 3
tmux select-layout tiled
tmux select-layout main-vertical

Directional resizing changes the selected pane’s boundary when the layout allows it. even-horizontal distributes side-by-side panes; even-vertical stacks them; main-vertical gives a large pane on the left; main-horizontal gives a large pane above; tiled forms a grid.

Default prefix + Control+arrow resizes in small steps; prefix + Alt+arrow uses larger steps, if the terminal transmits those combinations. Commands from the tmux prompt are a reliable fallback when the terminal or desktop intercepts shortcuts.

A sensible limit

If a split reports “no space for new pane”, enlarge the terminal, unzoom, close an unneeded pane, or create a new window. Six tiny panes are often less useful than two readable ones.

Move a pane without restarting its program

Run in your shell
tmux list-panes -a -F '#{pane_id} #{session_name}:#{window_index}.#{pane_index}'
# Example IDs: substitute IDs from your own output.
tmux break-pane -s %3
tmux join-pane -s %3 -t %1 -h

break-pane moves a pane into a window of its own. join-pane moves an existing pane into another window as a split. The program continues running in the same pane. Source and target must be distinct valid panes on the same server.

To close a shell cleanly, type exit. If it contains a foreground job, first decide whether to stop that job with its normal quit operation. Closing a pane is not equivalent to detaching: it can terminate the work.

Pause and test your understanding

Remember in 30 seconds

  • % / -h = side by side; quote / -v = stacked.
  • Focus determines where you type; zoom changes only the view.
  • Use -c for a predictable directory and IDs when moving panes.
