Module 07 / 18 · about 30 minutes

Scroll, search, copy & the clipboard

Inspect output without losing your place and understand the difference between tmux buffers and your desktop clipboard.

By the end, you can…

  • Use copy mode with both Emacs and vi keys.
  • Search retained output and manage paste buffers.
  • Choose and diagnose a clipboard integration.

There are several different histories

Shell history remembers command lines. tmux pane history remembers terminal output. Your terminal emulator may have its own scrollback. These are separate stores. Pressing the mouse wheel may interact with an application, your terminal, or tmux depending on settings.

Enter tmux copy mode with Ctrl+b then [. The pane stops following new output while you inspect its history; the program itself keeps running. Leave with q in vi mode or Esc in Emacs mode. Current bindings are the final authority.

Run in your shell
tmux show-window-options -v mode-keys
tmux list-keys -T copy-mode
tmux list-keys -T copy-mode-vi

The mode-keys option chooses Emacs or vi behavior; environment settings can influence its default. Explicitly set it during practice so you know which set you are using.

  1. Generate output with seq 1 200 in a practice pane.
  2. Enter copy mode, press ?, type 150, and press Enter to search backward through older output.
  3. Press Space to start selection, move to extend it, then Enter to copy and leave.
  4. Paste into a safe editor or an empty prompt using prefix then ]. Inspect pasted text before executing anything.

n invokes search-again and N search-reverse; their direction follows the preceding search. If your terminal captures Ctrl+Space or Alt+w, use vi mode or customize the binding.

Run in your shell
tmux list-buffers
tmux show-buffer
tmux save-buffer ~/tmux-selection.txt
tmux load-buffer ~/tmux-selection.txt
tmux delete-buffer

Prefix then = opens the buffer chooser. A buffer can be named with set-buffer -b name and selected using paste-buffer -b name. save-buffer writes to the machine running the tmux server, which might be remote. Deleting a buffer does not erase copies already written elsewhere.

history-limit limits scrollback per pane. Set it before creating panes; increasing it does not recover discarded lines and existing panes keep their creation-time limit. Full-screen applications can use an alternate screen, so their output may not remain in ordinary scrollback.

Choose the bridge that matches your environment

EnvironmentCommon approachWhat must be true
macOS desktopcopy-pipe-and-cancel 'pbcopy'pbcopy runs on the Mac with access to its clipboard.
Linux Wayland desktopcopy-pipe-and-cancel 'wl-copy'wl-clipboard is installed and the server can reach the Wayland session.
Linux X11 desktopcopy-pipe-and-cancel 'xclip -selection clipboard'xclip is installed and DISPLAY / X authentication are correct.
SSH to another machineOSC 52 with set-clipboard externaltmux knows the Ms capability and your local terminal allows clipboard writes.
Configuration example — choose the command for your OS
set -s set-clipboard external
# Optional vi-style y binding for a LOCAL macOS tmux server:
bind -T copy-mode-vi y send-keys -X copy-pipe-and-cancel 'pbcopy'

external permits tmux to set the outer clipboard while preventing applications inside tmux from creating tmux paste buffers through that mechanism. It does not guarantee every terminal supports OSC 52. Check tmux info for Ms and the terminal’s clipboard settings.

A remote pbcopy does not magically control your laptop clipboard. First confirm copying works inside tmux with show-buffer, then investigate the bridge separately. When mouse mode is on, the terminal’s own text selection may need a modifier such as Shift; the exact override is terminal-specific.

Copying output can copy secrets

Scrollback, paste buffers and exported captures may contain tokens, passwords or private records. Review content before sharing or logging it.

Pause and test your understanding

Remember in 30 seconds

  • Copy mode pauses your view, not the program.
  • tmux buffers and the OS clipboard are separate.
  • Check mode-keys and the clipboard bridge before changing random bindings.
