Open the complete question bank for reading or printing
You installed tmux on your laptop. Where must it run to protect a job on an SSH server?

On the remote server, with the job inside its pane

The tmux server and job need to share the remote host so the SSH client can disconnect without removing their terminal.

Review this topic
How do you use the default detach shortcut?

Hold Ctrl and press b, release both, then press d

tmux first enters its prefix key table; d is then interpreted as detach-client.

Review this topic
You opened the tmux command prompt with prefix :. What do you enter to list sessions?

list-sessions

The prompt already interprets tmux commands. The executable name is needed at a shell prompt.

Review this topic
Which check tells you the installed tmux executable version?

tmux -V

Capital V prints the client executable version. Compare the running server version separately after upgrades.

Review this topic
You type a command while two panes are visible. Who receives normal input?

The foreground program in the active pane

The selected session, current window and active pane determine the input destination.

Review this topic
A script needs to keep targeting a pane after rearranging its layout. Which target is best?

The captured pane ID, such as %7

Pane IDs stay with a pane for its lifetime on one server. Capture the ID when creating it.

Review this topic
tmux ls shows nothing, but you created work using -L training. What should you check first?

tmux -L training ls

A different socket name selects a different server. Inspect the server where the session was created.

Review this topic
Two sessions link to the same window. Are its programs duplicated?

No, both links refer to the same window and programs

Linking changes which sessions can reference a live window; it does not clone processes.

Review this topic
A long job is running in tmux. You detach. What changes?

The client disconnects; the job keeps running on its host

Detaching changes attachment, not process execution. Host and logout policy still determine lifetime.

Review this topic
You are already inside tmux and want another existing session on the same server.

Use tmux switch-client -t target

This changes the session displayed by your existing client without nesting another client.

Review this topic
A host rebooted. What can tmux itself restore?

No live processes; recreate the workspace and recover application data

Process memory and the tmux server ended. Recovery needs saved files, checkpoints or appropriate supervision.

Review this topic
You want to end only the disposable session api after inspecting it.

tmux kill-session -t '=api'

This explicitly targets the exact session name. Stop important applications cleanly first.

Review this topic
Which default sequence creates a new window?

Prefix then c

c creates a new-window; its first pane normally starts a shell.

Review this topic
A window is hidden while you view another one. What happens to its program?

It continues running

Window selection affects the view. Background windows retain live panes.

Review this topic
You want to jump repeatedly between the current and previous window.

Prefix then l

Lowercase l selects the last window. This is useful for an editor/test loop.

Review this topic
A shared window is linked in two sessions. What does kill-window do?

Destroys that window and removes its links from both sessions

Use unlink-window when you only intend to remove a session’s link, accounting for last-link behavior.

Review this topic
You want two panes next to each other, left and right.

split-window -h, or prefix %

Horizontal placement means panes along the horizontal axis; the dividing line is vertical.

Review this topic
You zoomed a pane and now only one is visible. How do you restore the arrangement?

Prefix then z again

Zoom toggles the view while preserving the other panes and their programs.

Review this topic
New splits should start in the current pane’s directory. What should the split command include?

-c "#{pane_current_path}"

The format is expanded by tmux; quoting preserves directories containing spaces.

Review this topic
You need to move a running pane into a window of its own.

break-pane

This changes the pane’s container without restarting its program.

Review this topic
After entering vi copy mode, what selects and copies text using default bindings?

Space starts selection; Enter copies and leaves

These are vi-table keys after entering copy mode. No prefix is needed for these mode actions.

Review this topic
show-buffer contains the right text, but the desktop paste is old. Where is the likely problem?

The clipboard bridge between tmux and the outer terminal/desktop

Internal copying succeeded. Inspect OSC 52 support or the local clipboard command and environment.

Review this topic
You increased history-limit after important lines were discarded. Can it recover them?

No; it cannot recreate discarded output

Set the limit before creating future panes and use persistent logs for important evidence.

Review this topic
What is the difference between capture-pane and pipe-pane?

capture-pane snapshots retained content; pipe-pane can stream future output

Choose capture for current evidence and a pipe or application logs for ongoing recording.

Review this topic
You removed a setting from the config and ran source-file. Why is its value still active?

Reload executes remaining commands but does not undo deleted lines

Explicitly restore the intended value or unset the relevant override; test clean startup separately.

Review this topic
The global value looks right but one session behaves differently.

Inspect a local override and inherited effective values

A target-local option can mask the global fallback. Check both scopes.

Review this topic
Typing is duplicated into every pane of a window. What should you inspect?

synchronize-panes

This window option broadcasts input. Turn it off and inspect any commands already sent.

Review this topic
A new prefix binding works, but an application shortcut stopped working after bind -n.

The root-table binding may consume the key without a prefix

bind -n installs a root binding; choose a prefix binding when applications need the raw key.

Review this topic
The tmux session exists after your break. Does that prove the long job succeeded?

No; inspect application output, status and results

The shell/session can remain alive after a failed job. Workspace existence is not health evidence.

Review this topic
Your service needs restart-on-failure and restart-after-reboot.

Use an appropriate service manager or scheduler

tmux helps with interaction but does not automatically supervise or restart arbitrary services.

Review this topic
You captured a pane on a remote tmux server using a remote shell. Where is the redirected file?

On the remote shell’s filesystem at the chosen path

Shell redirection occurs where that shell runs. Transfer or share it deliberately after inspection.

Review this topic
You are debugging a production-looking error in a practice environment. What is the best first step?

Reproduce a small case and collect relevant evidence

A narrow reproduction plus timestamps and logs helps distinguish causes before changes.

Review this topic
After reconnecting, tmux cannot find your session. What context should you verify first?

Host, user and socket

The same session name on another machine, account or socket refers to different state.

Review this topic
Two default Ctrl+b tmux layers are nested. How do you detach the inner layer?

Ctrl+b, Ctrl+b, then d

The outer default send-prefix binding forwards the inner prefix; d then reaches the inner table.

Review this topic
You want a second terminal to observe a session without sending normal typing.

tmux attach-session -r -t name

A read-only client reduces accidental input. It still displays the session’s contents and is not a secrecy boundary.

Review this topic
Git’s SSH agent access broke only in an old pane after reconnecting.

Compare SSH_AUTH_SOCK in the old shell and refreshed session environment

Existing processes retain their environment. A new pane may inherit an updated agent socket while the old shell keeps a stale one.

Review this topic
send-keys returned zero. What does that actually prove?

The input was sent to the targeted pane

It does not verify that a shell was ready, the intended command ran, or the command succeeded.

Review this topic
A launcher runs twice. How can it avoid duplicating windows during sequential use?

Check for the exact session and create its layout only when absent

This supports sequential reuse. Handle partial state and concurrent creation separately.

Review this topic
Why use new-session -P -F '#{pane_id}' in a launcher?

To capture the identity of the pane just created

The returned ID avoids assumptions about server-global counters or customized pane indexes.

Review this topic
A worker signals a wait-for channel. What else should a robust script check?

The worker’s recorded result/exit status and a timeout policy

A signal coordinates progress but does not itself encode success. A missing signal must not block forever.

Review this topic
What does a saved window_layout string preserve?

Pane arrangement, not live process memory

Restoring geometry is distinct from restoring files, environments or running applications.

Review this topic
Two sessions are in one group. What can be independent?

Their current window selection

Grouped sessions share their window list but can view different current windows. Programs and pane state remain shared.

Review this topic
After upgrading the tmux package, a new command still fails in an existing session.

Check the running server version as well as tmux -V

An existing server can still be the old version. Plan any restart around its running work.

Review this topic
What does a separate -L experiment server isolate?

tmux state such as sessions and options, but not filesystem permissions

Its programs still run as your user. A separate socket is not an OS security sandbox.

Review this topic
A screen stopped updating after Ctrl+s. Software flow control is enabled. What can resume it?

Ctrl+q

With XON/XOFF flow control active, Ctrl+q resumes output. Also distinguish copy mode, a busy app and a dead connection.

Review this topic
Inside tmux, an app has broken colors. Someone hardcoded TERM=xterm-256color in shell startup.

Remove the override and use an installed tmux/screen terminfo entry inside

TERM should describe the terminal interface the application actually sees. Verify terminfo on each relevant host.

Review this topic
An interactive tmux attach launched by noninteractive SSH reports 'not a terminal'.

Allocate a TTY with ssh -t, or use detached commands for automation

Interactive clients need a terminal. Automated setup can use new-session -d instead.

Review this topic
What makes a troubleshooting fix complete?

Verify the intended behavior and check for unintended effects

A diagnosis should connect symptom, evidence, cause, correction and an observable result.
