Practice Studio: make Git stick

Move snapshots, place branch pointers, investigate incidents and retrieve what you know. A visual practice session with room to experiment.

By the end, you can…

  • Predict which content a command will record.
  • Read a commit graph and place the resulting branch pointer.
  • Choose a recovery action from evidence and practise weak recall topics.

Choose a practice station

Learn by changing the picture

Predict. Try. Explain. Repeat.

Start with one station. Notice what moves and what stays. Say why the result makes sense before moving on.

No timer, no lost lives. Every mistake comes with a reason.

Practice model

The studio changes browser models only. It does not run Git or touch a repository. The real Git labs let you verify the same ideas in a terminal. Completed goals and recall results use your existing exportable learning progress.

01 · Watch a snapshot move

One file, three versions of reality. Change the working file, stage its current content, then commit. Each lane shows the actual content held in that part of this model.

02 · Where does the branch go?

Read the operation and move the branch badge to its resulting commit. Dragging is optional: tap or keyboard-select a commit, then check. Dashed circles are possible new commits for this prediction.

03 · You are on call for the repository

Open the evidence cards, choose the next step, and explain the outcome. A wrong choice stays at the current step so you can learn from its consequence.

04 · Connect an intention to a command

Choose one intention and its matching command. Work from the effect you need. Both columns stay visible: the challenge is understanding the match, not guessing where a card was hidden.

05 · A small recall round

Five questions, about five minutes, without a countdown. Previously missed studio questions come first. Make a prediction before reading the explanation, then retry the questions you missed. These answers are separate from your full quiz attempt.

Remember in 30 seconds

  • Name the layer before choosing the command.
