Practise with pictures and buttons

Need help with HEAD, index, staging, or diff?
Your file
What you are editing now. Git calls the project files the working tree.
Staging area = index
The file content you chose for the next commit. These are two names for one place.
HEAD
Tells Git which saved commit you are using, usually through your current branch.
Diff
A comparison showing added and removed lines between two versions.

Practice model

The studio changes browser models only. It does not run Git or touch a repository. The real Git labs let you verify the same ideas in a terminal. Completed goals and recall results use your existing exportable learning progress.

01 · Watch a saved version move

One file can have different text in your editor, in staging, and in the current saved commit. Change the working file, stage its current content, then commit. Each lane shows the actual content held in that part of this model.

02 · Where does the branch go?

Read the operation and move the branch badge to its resulting commit. Dragging is optional: tap or keyboard-select a commit, then check. Dashed circles are possible new commits for this prediction.

03 · You are on call for the repository

Open the evidence cards, choose the next step, and explain the outcome. A wrong choice stays at the current step so you can learn from its consequence.

04 · Connect a task to a command

Choose one task and its matching command. Work from the effect you need. Both columns stay visible: the challenge is understanding the match, not guessing where a card was hidden.

05 · A small recall round

Five questions, about five minutes, without a countdown. Previously missed studio questions come first. Make a prediction before reading the explanation, then retry the questions you missed. These answers are separate from your full quiz attempt.

What to remember

  • Say whether you need to change your file, staging, or saved history.
  • Predict where the branch will point and which earlier commits it will include.
  • Use mistakes as a shortlist for your next recall session.
