Lesson 19 / 23 · read at your own pace

See what the commands change

Move through history pictures, fix a settings conflict, and find why a push or access check is refused.

Need help with HEAD, index, staging, or diff?
Your file
What you are editing now. Git calls the project files the working tree.
Staging area = index
The file content you chose for the next commit. These are two names for one place.
HEAD
Tells Git which saved commit you are using, usually through your current branch.
Diff
A comparison showing added and removed lines between two versions.
Watch these change with one file →

By the end, you can…

  • Read branch names and earlier-commit links.
  • Keep two required values when fixing a conflict.
  • Explain why a push or access check succeeds or fails.

How to read these pictures

Each circle is a saved commit. A, B, and C stand for real commit IDs. Lines link a commit to earlier commits. A label such as main tells you which commit the branch names. Earlier work is on the left; later work is on the right.

Buttons change these examples, not a real project or account. If a word is unfamiliar, open the word list.

1 · Before and after each history command

Choose a story. Read the starting point, predict the next picture, then use Next step. Read what moved and what stayed.

2 · Keep the needed values from both sides

Timeout is a wait limit. Retries is how many times to try again. The requirement is timeout 20 and retries 3. JSON is the settings format below. Make one valid settings object with both values.

3 · A teammate pushes while you change history

Your replacement is C′. The old server commit was C. Your teammate may have added T. A lease checks whether the server is still at an expected commit, not whether your files keep every needed change.

4 · Find the missing access check

A role gives an account project access. A token is its limited secret key. A branch rule can still require a PR, reviews, and tests. Change one setting at a time.

What to remember

  • Branch labels name commits; lines show earlier history.
  • A conflict fix needs the right values as well as valid punctuation.
  • An expected-ID check and an access role each check only part of the action.
