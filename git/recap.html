Need help with HEAD, index, staging, or diff?
Your file
What you are editing now. Git calls the project files the working tree.
Staging area = index
The file content you chose for the next commit. These are two names for one place.
HEAD
Tells Git which saved commit you are using, usually through your current branch.
Diff
A comparison showing added and removed lines between two versions.

Try 20–30 minutes when that suits you. Repeat difficult exercises in a new practice folder. You do not need to finish every topic in one sitting.

Before changing shared history

  • Read status. Confirm the project, branch, and remote.
  • Keep wanted edits and the old committed position.
  • Fetch and read the shared work you will affect.
  • Agree with anyone using the branch before replacing commits.
  • Check final files, history, and tests before sending the result.

Keep a copy of your progress
